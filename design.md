- Overview
Academic Manager is divided into different Python files.Each file handles a specific part of the project.

- Modules
AcademicManager.py - Main menu and program control
timetable.py - Adds and display classes
assignments.py - Adds and display assignments
scheduler.py - Adds study hours and creates a study plan
progress.py - Tracks assignments progress

- Basic Workflow
Start > Main menu > Select an option > Perform the task > Show result > Back to main menu > Exit

- Data Structures
The project uses:
Lists to store data.
Dictionaries to store class and assignment details.
Tuples to store study, day and time.

- Design Approach
The project uses separate modules to keep the code simple and organized.Each module has a specific task, making the project easier to understand and modify.
