Academic Manager

- Project Overview
Academic Manager is a simple Python program that helps students manage their timetable, assignments, study hours and progress.
This project was developed for the VITyarthi "Build Your Own Project" component of Introduction to Programming and Problem Solving.

- Problem Statement
Managing classes, assignments, deadlines, and study time can be difficult for students. The Academic Manager provides a simple way to organize these activities and create a basic study plan.

- Features
Add and view classes and assignments
Set assignment priority
Add study hours
Generate a study plan
Mark assignments as completed
view progress

- Technologies Used
Python
Visual Studio Code
Git and GitHub

- Python Concepts Used
Lists, Dictionaries, Tuples, Functions, Loops, Conditions, Append(), input(), print() and modules.

- Project Structure = AcademicManager
AcademicManager.py - Main menu
timetable.py - Manages classes
assignments.py - Manages assignments
scheduler.py - Manages study hours and plans
progress.py - Tracks assignments progress

- How to Run
open the project in VS Code and run:
python AcademicManager.py

- Testing
The project can be tested by adding classes, assignments, and study hours, generating a study plan, completing assignments, and checking progress.

- Limitations
Data is not permanently stored.
The scheduling system is basic.
There is no database or graphical interface.

- Future Enhancements
Permanent data storage.
Deadline and priority - based scheduling.
Weekly progress reports.
Graphical user interface.

- Conclusion
Academic Manager uses basic Python concepts to solve a practical student time - management problem through a simple command - line application.
