Academic Manager

- Problem Statement
Students need to manage classes, assignments, deadlines, and study time. Managing all these activities can be difficult and stressful.
Academic Manager provides a simple Python - based solution to organize academic information and create a basic study plan.

- Scope
The project focuses on basic academic management.It allows students to:
Manage their timetable and assignments.
Add available study hours.
Generate a simple study plan.
Track assignment progress.

- Target Users
The main users of this project are college students who want a simple way to organize their academic tasks and study time.

- High Level Features
Timetable Management - Add and view classes.
Assignment Management - Add assignments and set their priority.
Study Planning - Add study hours and generate a simple study plan.
Progress Tracking - Mark assignments as completed and view progress.

- Expected Outcome
The project provides a simple command - line application that students oraganize their academic activities using basic Python programming concepts such as lists, dictionaries, tuples, functions, loops, conditions, append(), input(), print() and modules.
