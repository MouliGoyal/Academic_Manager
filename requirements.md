- Functional Requirements

The system should:
1. Allow the user to add and view classes and assignments.
2. Allow the user to set assignment priority.
3. Allow the user to add available study hours.
4. Generate a simple study plan using the entered study hours.
5. Allow the user to mark assignments as completed.
6. Display completed and pending assignments.
7. Provide a menu for accessing all major features.

- Non - Functional Requirements

The system should:
1. Be simple and eay to use.
2. Give clear messages for user actions and invalid choices.
3. Respond quickly to user input.
4. Use a modular and organized Python structure.
5. Use basic Python concepts covered in the course.
6. Be easy to maintain and modify.
